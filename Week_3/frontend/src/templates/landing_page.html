How it works

The full AI pipeline

From your browser to the AI model — here's every step that happens when you send a message.

1

You type a message in the browser

The frontend (FastAPI + Jinja2) serves the chat page. JavaScript captures your input and optionally reads a PDF file using PDF.js to extract text client-side.

FastAPI Jinja2 PDF.js Bootstrap
2

Frontend sends JSON to the backend

JavaScript calls POST /chat on the backend with a JSON payload containing your message and any PDF text. The backend URL is set via environment variable — never hardcoded.

fetch() API JSON .env
3

Backend detects intent & routes the request

The backend (FastAPI) checks what you asked. "Find skills gap" → calls the skill gap function. Anything else → calls general chat. CORS middleware allows the frontend to communicate cross-port.

FastAPI CORS Pydantic
4

AI model processes your request

General chat uses Ollama running locally on your machine (phi3 model). Skill gap analysis uses Gemini to extract skills from your resume, then compares them against a SQLite jobs database.

Ollama (phi3) Gemini API SQLite
5

Reply appears in the chat

The backend returns JSON {"reply": "..."} to the frontend. JavaScript renders it as a chat bubble in the conversation history.

JSONResponse DOM

How to use

Get started in 4 steps

Everything runs locally or in Docker containers.

01

Start Ollama

Run ollama serve to start the local AI model on port 11434.

02

Run the backend

Start the FastAPI backend on port 8001 — locally or via Docker container.

03

Run the frontend

Start the FastAPI frontend on port 8000 — locally or via Docker container.

04

Open the chatbot

Go to localhost:8000 and start chatting or upload your resume!
