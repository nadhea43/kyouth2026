Lets Get Started

📌 What is this pipeline?

This project uses Large Language Models (LLMs) to analyze resumes, identify gap skills (skills missing from your resume but present in job descriptions), and provide interactive Q&A support.

⚙️ How to Build

  • Frontend: FastAPI + Jinja + Bootstrap
  • Backend: FastAPI POST /chat endpoint
  • LLM Integration: Ollama (local) + Gemini
  • Containerization: Dockerfiles for frontend & backend
  • Orchestration: Docker Compose for multi-service setup

🚀 How to Use

  1. Upload your resume (PDF).
  2. System extracts text and compares with job database.
  3. Gap skills are displayed.
  4. Chat with the AI assistant for career guidance.
